# BirdBuddy API — Functional Test Scenarios

This document contains the results of a three-stage functional test analysis performed against the BirdBuddy API specification (birdbuddy-api-spec-updated-gpt-5-mini.md).

## Stage 1 — Functional Requirements

| Name | Description | Reference |
| ---- | ----------- | --------- |
| AUTH_REQUIRED | All API requests require authentication via X-API-Key or Authorization: Bearer <token>. | Authentication and Authorization |
| AUTH_API_KEY | API Key supplied in `X-API-Key` header is supported and should authenticate requests. | Authentication and Authorization |
| AUTH_BEARER | Bearer token via `Authorization: Bearer <token>` is supported where applicable. | Authentication and Authorization |
| AUTH_401 | When authentication is missing or invalid the API returns 401 Unauthorized. | Authentication and Authorization |
| AUTH_403 | When authentication is present but actor lacks permission the API returns 403 Forbidden. | Authentication and Authorization |
| RATE_LIMIT_PER_TOKEN | Rate limits are enforced per API key (per-token), with endpoint-specific defaults. | Rate Limiting (Rate limit per-token defaults table) |
| RATE_LIMIT_ENDPOINT_DEFAULTS | Default per-token limits per endpoint (Search=60/60s, Retrieve=60/60s, Add=10/60s, Update=10/60s, Delete=60/60s). | Rate limit per-token defaults table |
| RATE_LIMIT_RESP_HEADERS | Responses include X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; 429 includes Retry-After. | Rate Limiting |
| RATE_LIMIT_429 | When the rate limit is exceeded the API returns 429 Too Many Requests and includes Retry-After. | Rate Limiting |
| ERROR_SCHEMA | All error responses follow JSON schema: { "code": number, "message": string, "details": null|object|array }. | Error Response Schema |
| BIRD_UUID_SERVER_GEN | `uuid` is a UUID v4 generated by the server; it must not be supplied in create requests. | Bird Data Model & Add a New Bird notes |
| BIRD_NAME | `name` string is required on create; min 1 and max 100 characters. | Bird Data Model & Add a New Bird |
| BIRD_SCI_NAME | `scientificName` string is required on create; min 1 and max 200 characters. | Bird Data Model & Add a New Bird |
| BIRD_DESCRIPTION | `description` string required on create; min 1 and max 5000 characters. | Bird Data Model & Add a New Bird |
| BIRD_PRIMARY_COLOR | `primaryColor` is required on create and must be one of the specified enum values. | Bird Data Model & Add a New Bird |
| BIRD_SECONDARY_COLOR | `secondaryColor` is an array of allowed color enums, max 10 values; duplicate values are ignored. | Bird Data Model |
| BIRD_FLIGHT_PATTERN | `flightPattern` enum: linear, sine, circle, grounded. | Bird Data Model |
| BIRD_SIZE | `size` required on create; allowed values: small, medium, large. | Bird Data Model & Add a New Bird |
| BIRD_SONG | `song` string min 1 and max 200 characters. | Bird Data Model |
| BIRD_AREA | `area` array of location strings; max 50 values. | Bird Data Model |
| BIRD_TIME | `time` array of strings, allowed values: morning, afternoon, evening, night; max 4 distinct values. | Bird Data Model |
| BIRD_MIGRATORY | `migratory` boolean or null (optional). | Bird Data Model |
| SEARCH_ENDPOINT | GET /birds returns a paginated list with top-level fields: total, limit, offset, data (array of bird objects). | Search for Birds |
| SEARCH_FILTERS_AND | Different filter parameters provided in a single request are combined using logical AND. | Search for Birds |
| SEARCH_FILTERS_MULTI_OR | Multi-valued parameters (repeated query keys, e.g., secondaryColor=teal&secondaryColor=blue) are combined using logical OR for that parameter. | Search for Birds |
| SEARCH_REPEATED_DUPLICATES_IGNORED | Duplicate repeated query values are ignored for multi-valued parameters. | Search for Birds (secondaryColor / repeated keys notes) |
| SEARCH_LIMIT_OFFSET_DEFAULTS | `limit` defaults to 25 (allowed 1-100). `offset` defaults to 0 (zero-based). | Search for Birds |
| SEARCH_INVALID_PARAM_400 | Invalid query parameter values (e.g., time=supper) return 400 with descriptive message listing allowed values. | Search for Birds (invalid example) |
| SEARCH_NO_MATCHES_200 | When no records match the query, response is 200 with total=0 and data=[]. | Search for Birds (example) |
| RETRIEVE_BY_ID_ENDPOINT | GET /birds/{uuid} returns a single bird object conforming to Bird Data Model. | Retrieve a Bird by ID |
| RETRIEVE_INVALID_UUID_400 | Invalid UUID format for path parameter returns 400 with error schema. | Retrieve a Bird by ID |
| RETRIEVE_NOT_FOUND_404 | No bird with the specified uuid returns 404 Not Found with error schema. | Retrieve a Bird by ID |
| CREATE_BIRD_ENDPOINT | POST /birds creates a new bird; required fields: name, scientificName, description, primaryColor, size. | Add a New Bird |
| CREATE_VALIDATION_400 | Missing or invalid parameters in create request return 400 with details field. | Add a New Bird |
| CREATE_DUPLICATE_409 | Creating a bird that duplicates an existing bird (same name & scientificName) returns 409 Conflict. | Add a New Bird |
| CREATE_RESPONSE_201 | Successful create returns 201 Created and the created bird object including server-generated uuid. | Add a New Bird |
| UPDATE_BIRD_ENDPOINT | PATCH /birds/{uuid} updates provided fields only; `uuid` cannot be changed. Only supplied fields are validated and updated. | Update a Bird |
| UPDATE_VALIDATION_400 | Invalid field values provided in PATCH return 400 with details. | Update a Bird |
| UPDATE_DUPLICATE_409 | Updating a bird in a way that creates a duplicate record returns 409 Conflict. | Update a Bird |
| UPDATE_INVALID_UUID_400 | Invalid UUID format in update path parameter returns 400. | Update a Bird |
| UPDATE_RESPONSE_200 | Successful update returns 200 OK with the updated bird object. | Update a Bird |
| DELETE_BIRD_ENDPOINT | DELETE /birds/{uuid} deletes the bird; successful deletion returns 204 No Content. | Delete a Bird |
| DELETE_INVALID_UUID_400 | Invalid UUID format for delete path parameter returns 400. | Delete a Bird |
| DELETE_NOT_FOUND_404 | No bird with the specified uuid returns 404 Not Found. | Delete a Bird |
| HEADERS_REQUIREMENT | All endpoints require `Accept: application/json`. POST and PATCH require `Content-Type: application/json`. | Endpoint header lines for each endpoint |
| STATUS_CODES_GENERAL | API may return 500 Internal Server Error or 503 Service Unavailable; such responses follow the common error schema. | Status Codes across endpoints |
